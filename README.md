# 自律大师 6.1（Self-Discipline Master）

> 个人任务管理与专注工具，帮助你更好地掌控日程、提高学习与工作效率。

一个**单文件、无依赖、可离线运行**的自律追踪应用，用浏览器直接打开 `index.HTML` 即可使用，所有数据保存在本地（localStorage），支持导出 / 导入备份。

## ✨ 功能总览

| 模块 | 能力 |
| :--- | :--- |
| 📋 任务 | 优先级（高/中/低）、日期、编辑/删除、四种筛选、快捷添加、今日进度 |
| 🌱 习惯 | 连续打卡、7 日圆点、可折叠年度热力图、习惯排行榜 |
| 😊 心情 | 5 档心情记录、心情日历、趋势、与专注时长关联图 |
| 🍅 番茄钟 | 专注/休息时长可调、沉浸式专注、后台不漂移、自动衔接休息、提示音 |
| 📊 统计 | 完成率、周对比、专注柱图、成绩曲线、连续打卡日历 |
| 🏆 徽章 | 14 枚成就徽章 + 成就进度 |
| 💾 数据 | JSON 导出 / 导入 / 一键清空，数据完整性与迁移机制 |

**沉浸专注模式**：🌌 太空星际 / 🌿 森林自然 两套全屏专注界面。

## 🚀 使用方式

- **直接使用**：用 Chrome / Edge / Safari 打开 `index.HTML`。
- **数据备份**：设置页 → 导出数据（JSON），换设备后导入即可恢复。
- **番茄钟**：可设置专注/休息时长；默认专注结束后自动进入休息，可在设置中关闭；结束时有提示音与通知。
